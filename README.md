## 🧭 About Me

I'm a software engineer who enjoys the full stack but is increasingly drawn to what happens **beneath the UI** — API design, data flow, caching, and the architectural decisions that determine how systems behave as they grow.

During my time at **Seaflux Technologies**, I worked on customer-facing applications, reusable frontend components, backend integrations, and a cloud-based content pipeline that streamlined the content-publishing workflow.

Outside of professional work, I build engineering-focused projects to explore **backend architecture, distributed systems, caching, authentication, scalability, and performance**.

Right now, I'm strengthening my foundations in **C++, Data Structures & Algorithms, Low-Level Design, and System Design**, with a growing interest in performance-oriented and systems engineering.

### 🔗 ShortLink

**Distributed URL Shortener**

</div>

A horizontally-scaled URL shortening service designed to explore real-world backend architecture, caching, rate limiting, load balancing, and performance.

**⚡ Engineering Highlights**

* PostgreSQL persistence + Redis caching
* Base62 short-code generation + click tracking
* Redis-based rate limiting using `INCR / TTL`
* Dockerized stack + Nginx load balancing across **2 API instances**
* k6 load testing: **1,500 requests · ~49 req/s · 0% failures**
